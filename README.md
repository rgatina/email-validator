# Валидатор email-адресов на регулярных выражениях (Кейс 9)

Консольная программа на Python для проверки корректности email-адресов.
Поддерживает одиночную и пакетную проверку, выводит подробную причину
ошибки для каждого некорректного адреса и сохраняет историю всех проверок.

## Возможности

- проверка одного адреса, введённого вручную;
- пакетная проверка адресов из текстового файла (по одному на строку);
- сохранение результатов пакетной проверки в `results.txt` с пометками
  «корректен» / «некорректен» и причинами ошибок;
- проверка адреса по пользовательскому регулярному выражению
  (опциональная задача кейса);
- просмотр истории последних 20 проверок;
- сохранение истории всех проверок в `history.json`
  (время, адрес, результат, причина ошибки);
- обработка ошибок: файл не найден, нет прав, пустой файл, неизвестная
  кодировка, некорректное регулярное выражение, пустой ввод.

## Требования

- Python 3.8+;
- сторонние библиотеки не требуются (только стандартная библиотека).

## Запуск

```bash
python email_validator.py
```

## Меню программы

```
 1 — проверить один адрес вручную
 2 — пакетная проверка адресов из файла
 3 — проверка по своему регулярному выражению
 4 — просмотреть историю проверок
 0 — выход
```

## Тестовые данные

Файл `test_emails.txt` содержит контрольный набор адресов из задания
(корректные и заведомо некорректные). Для запуска пакетной проверки
укажите путь к этому файлу в пункте меню 2. Результат появится
в `results.txt`, а все проверки попадут в `history.json`.

## Регулярное выражение

Эталонный шаблон проверки (с комментариями по частям — в коде):

```
^(?!.*\.\.)(?\!\.)[A-Za-z0-9._+-]+(?<!\.)@
(?!\.)[A-Za-z0-9-]+(?:\.[A-Za-z0-9-]+)*(?<!\.)\.[A-Za-z]{2,6}$
```

Правила, которые он реализует:

- локальная часть: буквы, цифры, точки, дефисы, подчёркивания, плюс;
- обязательный символ `@` (ровно один);
- домен: буквы, цифры, дефисы, точки; без точки в начале и конце,
  без двух точек подряд;
- минимум одна точка в домене и доменная зона из 2-6 латинских букв.
